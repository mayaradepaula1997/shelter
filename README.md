# Gerenciamento de abrigos

## Descrição

Esta é uma API desenvolvida em Java com Spring Boot para gerenciar abrigos.
A aplicação permite criar, listar, edita e excluir abrigo, animal, funcionario, adoção, tratamento e vacina, que possuem relaciomentos entre cada classe. Utilizando PostgreSQL como banco de dados.


## Tecnologias Utilizadas

- Java 17
- Spring Boot 3.3.1
- PostgreSQL 16
- Maven

## Como usar a api


1. Clone o projeto do github.
2. Instale as dependências do projeto com o maven.
3. Instale o Postman em sua máquina. 
4. Crie as requisições Post, Get, Put e Delete das classes do projeto.
